Data Management: Interactions with Computer Architecture and Systems

This book explains the interactions among data management, computer architecture, and system software, with emphasis on building efficient data processing systems through hardware-software codesign.

It covers logical data formats, memory architecture, GPU programming, and the use of ray tracing in computation, while highlighting low data movement, high throughput, and low latency as central system goals.
